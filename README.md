# Full Stack Intern Assignment - Customer Feedback Platform

This project is a full-stack application that enables users to log in via Google, submit feedback, and view feedback data. The backend is built using Node.js, Express.js, and MongoDB, while the frontend is built with React.js. The application integrates with the Frill.co API for feedback management.

## Overview

This project has two primary parts:
1. **Backend**: Handles Google OAuth authentication, feedback submission, and integration with Frill.co for feedback storage.
2. **Frontend**: Provides a UI for login, feedback submission, and feedback display.

The application allows authenticated users to log in via Google, submit feedback, and view the feedback they have provided.

## Technology Stack

- **Frontend**: React.js, Axios, React Router
- **Backend**: Node.js, Express.js, Passport.js, Frill.co API
- **Database**: MongoDB
- **Authentication**: Google OAuth with Passport.js
- **API Integration**: Frill.co for feedback storage
